# Sprint 7

## О проекте
Репозиторий содержит автотесты для проверки API учебного веб-сервиса «Яндекс.Самокат».
Тесты написаны на **Python + Pytest** с использованием requests для HTTP-запросов и **Allure** для отчетности.

---

## Структура репозитория

```text
.
├── allure_results/                   # результаты для Allure
│
├── src/
│   ├── __init__.py
│   └── config.py                     # базовый URL и заголовки
│
├── tests/
│   ├── conftest.py                   # фикстуры Pytest
│   ├── test_create_courier.py        # тесты создания курьера
│   ├── test_login_courier.py         # тесты авторизации курьера
│   ├── test_create_order.py          # тесты создания заказа (параметризация по цветам)
│   └── test_get_list_of_orders.py    # тесты списка заказов
│
├── venv/                             # виртуальное окружение (локально)
├── README.md
└── requirements.txt                  # зависимости проекта

```

## Фикстуры (tests/conftest.py)
**register_new_courier_and_return_login_password**</br>
Регистрирует нового курьера через POST /api/v1/courier на https://qa-scooter.praktikum-services.ru и, если ответ успешный (201), возвращает список [login, password, first_name]. При неуспехе возвращает пустой список.</br>
**courier_payload**
Генерирует валидное тело запроса курьера: {"login": <rnd>, "password": <rnd>, "firstName": <rnd>}.

## Описание тестов

### `tests/test_create_courier.py` — **TestCreateCourier**
| Тест-кейс                                                        | Что проверяет                                                       |
|------------------------------------------------------------------|---------------------------------------------------------------------|
| Курьера можно создать                                            | Успешная регистрация при передаче валидного тела запроса (код 201). |
| Нельзя создать двух одинаковых курьеров                          | Повторная регистрация с теми же данными возвращает ошибку.          |
| Чтобы создать курьера, нужно передать все обязательные поля      | Отсутствие обязательных полей приводит к ошибке валидации.          |
| Запрос возвращает правильный код ответа                          | Проверка соответствия коду ответа спецификации.                     |
| Успешный запрос возвращает `{"ok": true}`                        | Проверка тела успешного ответа.                                     |
| Если одного из обязательных полей нет — запрос возвращает ошибку | Негативные сценарии по каждому обязательному полю.                  |
| Если логин уже существует — возвращается ошибка                  | Проверка возврата ошибки при дубликате логина.                      |

---

### `tests/test_login_courier.py` — **TestLoginCourier**
| Тест-кейс                                          | Что проверяет                                                    |
|----------------------------------------------------|------------------------------------------------------------------|
| Курьер может авторизоваться                        | Успешная авторизация существующего курьера, ответ содержит `id`. |
| Для авторизации нужны все обязательные поля        | Отсутствие логина или пароля дает ошибку валидации.              |
| Ошибка при неверном логине или пароле              | Негативные сценарии с некорректными учетными данными.            |
| Если какого-то поля нет — запрос возвращает ошибку | Проверка сообщений/кодов ошибок.                                 |
| Авторизация под несуществующим пользователем — ошибка | Корректная обработка несуществующих учетных записей.             |
| Успешный запрос возвращает `id`                    | Наличие идентификатора курьера в теле ответа.                    |

---

### `tests/test_create_order.py` — **TestCreateOrder**
| Тест-кейс                                         | Что проверяет                                              |
| ------------------------------------------------- |------------------------------------------------------------|
| Можно указать один из цветов — `BLACK` или `GREY` | Заказ успешно создается с каждым допустимым цветом.        |
| Можно указать оба цвета                           | Заказ успешно создается при множестве значений.                  |
| Можно совсем не указывать цвет                    | Цвет не является обязательным параметром.                  |
| Тело ответа содержит `track`                      | В успешном ответе присутствует идентификатор трека заказа. |
